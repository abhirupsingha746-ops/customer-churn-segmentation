# Customer Churn Segmentation and Recommendation Model

## Project Overview

This project analyzes customer data to identify customer segments and prioritize potential churn risk using a transparent, rule-based scoring system.

## Objectives

* Analyze customer behavior and account characteristics.
* Create customer segments based on tenure.
* Calculate observed churn rates for each segment.
* Develop and validate a rule-based churn-risk score.
* Recommend customer retention actions.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Project Files

* `Customer_Churn_Segmentation_Analysis.ipynb` — Analysis notebook.
* `customer_segmentation_results.csv` — Customer segment results.
* `step10_customer_retention_recommendations.xlsx` — Segment evidence and recommended actions.
* `Customer_Churn_Recommendation_Report.md` — Final project report.

## Key Finding

In the supplied sample of 15 customers, the New Customers segment had an observed churn rate of 100% (5 out of 5 customers). This small sample requires cautious interpretation.

## Limitations

The dataset is small, and the rule-based score is not a validated probability of future churn. The recommendations should be evaluated using additional data and subsequent customer-retention outcomes.
